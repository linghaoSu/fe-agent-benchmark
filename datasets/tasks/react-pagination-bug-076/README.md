# 分页越界与页码同步 Bug 修复

商品列表（`src/data/products.js`，共 23 条，每页 5 条）的分页组件收到以下 Bug 报告，请在 `src/` 中修复：

1. 在最后一页（第 5 页）继续点击「下一页」会进入第 6 页，列表变空；同样在第 1 页点击「上一页」会进入第 0 页。页码必须限制在 `1 … 总页数` 之间，处于边界时对应按钮应带 `disabled` 属性。
2. 页码指示器显示「第 1 / 4 页」，但实际应有 5 页（23 ÷ 5 需向上取整）。
3. 直接打开 `/?page=3` 时始终渲染第 1 页；URL 中的 `page` 参数应作为初始页码生效（第 3 页应显示第 11–15 条），并且翻页后 URL 应同步为 `?page=N`。

测试会使用以下 `data-testid`（已存在，请保留）：`product-row`（每行商品）、`prev-page`、`next-page`、`page-indicator`（文案格式「第 X / Y 页」）。上一页/下一页按钮需保留可访问名称（`aria-label`）。

不要修改依赖、`evaluator/` 或 `references/`。
